# Auto Timeline Sync

Private source archive for Auto Timeline Sync by Naimat.

- `Windows-3.0.2-A1/` contains the latest Windows application source and build tools.
- `Android-3.0.2-A1/` contains the Android source, assets and build tools.
- `Contract-Sync-3.0.2-A1/` contains the ATS 3.0.2-A1 contract and sync overlay.

Build instructions are in each platform folder. Generated build directories, emulator captures, APK/portable release binaries, local runtime junctions, and signing credentials are intentionally excluded. Android signing keys remain on the original machine and must be backed up separately if future APK updates need the same signing identity.
